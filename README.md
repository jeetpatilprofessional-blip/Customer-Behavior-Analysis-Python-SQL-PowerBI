# Customer Shopping Behavior Analysis

An end-to-end customer shopping behavior analysis project using **Python, PostgreSQL, SQL, and Power BI**. The project explores 3,900 purchase records to understand customer demographics, product preferences, spending patterns, discounts, shipping choices, and subscription behavior.

> **Learning-project attribution:** This repository is based on the YouTube tutorial and project materials by [Amlan Mohanty](https://www.youtube.com/@amlanmohanty1). The original project repository is [customer-trends-data-analysis-SQL-Python-PowerBI](https://github.com/amlanmohanty1/customer-trends-data-analysis-SQL-Python-PowerBI). This copy is maintained as a learning and portfolio exercise. Credit for the original tutorial and project structure belongs to the creator.

## Business problem

A retail company wants to better understand shopping behavior to improve sales, customer satisfaction, and long-term loyalty. The analysis investigates how demographics, product categories, discounts, reviews, shipping preferences, and purchase history relate to customer purchasing patterns.

**Main question:** How can the company use customer shopping data to identify trends, improve engagement, and optimize marketing and product strategies?

## Dataset

- **Records:** 3,900 purchases
- **Columns:** 18 original fields
- **Missing values:** 37 values in `Review Rating`
- **Main information:** customer demographics, products and categories, purchase amounts, location, season, ratings, subscription status, shipping type, discounts, previous purchases, payment method, and purchase frequency.

The dataset file included in this repository is `customer_shopping_behavior.csv`.

## Tools and technologies

- **Python:** Pandas for data loading, cleaning, transformation, and feature engineering
- **Jupyter Notebook:** step-by-step analysis in `Customer_Shopping_Behavior_Analysis.ipynb`
- **PostgreSQL / SQL:** database loading and business analysis queries
- **Power BI:** interactive dashboard in `customer_behavior_dashboard.pbix`
- **Presentation:** project summary and findings in the supplied PowerPoint

## Project workflow

### 1. Python: data preparation and feature engineering

The notebook performs the following steps:

1. Loads the CSV dataset with Pandas.
2. Inspects the dataset using `head()`, `info()`, and `describe()`.
3. Checks missing values.
4. Fills missing review ratings using the median rating within each product category.
5. Standardizes column names to lowercase snake_case and renames the purchase amount field.
6. Creates an `age_group` feature using age quartiles.
7. Converts purchase-frequency labels into an approximate number of days in `purchase_frequency_days`.
8. Checks whether `discount_applied` and `promo_code_used` contain the same information, then drops the redundant promo-code column.
9. Loads the prepared DataFrame into a SQL database. The notebook includes connection examples for PostgreSQL, MySQL, and SQL Server; the supplied SQL query file uses PostgreSQL-style syntax.

### 2. SQL: business questions

The file `customer_behavior_sql_queries.sql` contains queries to investigate:

1. Revenue generated by male and female customers.
2. Customers who used discounts but spent at least the average purchase amount.
3. Five products with the highest average review ratings.
4. Average purchase amount for Standard and Express shipping.
5. Average spend and total revenue for subscribers and non-subscribers.
6. Products with the highest percentage of discounted purchases.
7. New, Returning, and Loyal customer segments based on previous purchases.
8. Three most-purchased products within each category.
9. Subscription status among repeat buyers with more than five previous purchases.
10. Revenue contribution by age group.

### 3. Power BI: dashboard

Open `customer_behavior_dashboard.pbix` in Power BI Desktop to explore the customer behavior dashboard. The dashboard is intended to present customer and purchase patterns in a visual format for business users.

### 4. Report and presentation

- `Customer Shopping Behavior Analysis.pdf` – project report, analysis workflow, SQL questions, dashboard overview, and recommendations.
- `Customer-Shopping-Behavior-Analysis.pptx` – presentation summarizing the dataset, analysis process, selected findings, and recommendations.
- `Business Problem  Document.pdf` – original business problem and project deliverables.

## Findings highlighted in the supplied presentation

The accompanying presentation reports the following observations:

- Female customers generate slightly higher total revenue than male customers.
- Express-shipping customers have a reported average purchase amount of **$65**, compared with **$58** for Standard shipping.
- Subscribers are reported to spend more than non-subscribers.
- The presentation highlights opportunities to convert new customers into returning customers and returning customers into loyal customers.
- Product ratings and discount usage can help inform product positioning and promotional decisions.

These are findings reported in the supplied project presentation. Re-run the notebook and SQL queries against the dataset before using any figures as independently verified results or business claims.

## Business recommendations presented in the project

- Promote subscription benefits to encourage customer retention.
- Introduce loyalty initiatives for repeat customers.
- Review discount strategies while considering their impact on revenue and profitability.
- Highlight well-rated and popular products in marketing campaigns.
- Use customer segments and purchase patterns to inform targeted marketing.

## How to use

1. Clone this repository:
   ```bash
   git clone https://github.com/jeetpatilprofessional-blip/Customer-Behavior-Analysis-Python-SQL-PowerBI.git
   cd Customer-Behavior-Analysis-Python-SQL-PowerBI
   ```
2. Install the Python packages used by the notebook:
   ```bash
   pip install pandas sqlalchemy psycopg2-binary
   ```
3. Open `Customer_Shopping_Behavior_Analysis.ipynb` in Jupyter Notebook, JupyterLab, or VS Code.
4. Create a PostgreSQL database named `customer_behavior` and configure your own local database connection.
5. Run the notebook cells to prepare the data and load the `customer` table into PostgreSQL.
6. Run the queries in `customer_behavior_sql_queries.sql` using your PostgreSQL client.
7. Open `customer_behavior_dashboard.pbix` in Power BI Desktop. If prompted, configure the data source to your own database or data file.

**Database security:** Never commit real database passwords, API keys, or other credentials. Replace any example connection details in the notebook with your own local configuration; preferably load credentials from environment variables.
